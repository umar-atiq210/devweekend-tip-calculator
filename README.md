# Devweekend Tip Calculator

A highly responsive, reactive, and edge-case-proof Tip Calculator and Bill Splitter built for the Devweekend Frontend Assessment.

## Prerequisites
- Node.js (v18 or higher recommended)

## How to Run Locally

1. **Clone the repository** (if you haven't already):
   \`\`\`bash
   cd tip-calculator
   \`\`\`

2. **Install dependencies**:
   \`\`\`bash
   npm install
   \`\`\`

3. **Start the development server**:
   \`\`\`bash
   npm run dev
   \`\`\`

4. Open your browser and navigate to `http://localhost:5173`.
